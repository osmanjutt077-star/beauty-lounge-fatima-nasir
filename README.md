# Beauty Lounge by Fatima Nasir
Responsive Next.js App Router website with TypeScript, Tailwind CSS 4 and Framer Motion.

## Run
Node.js 20.9+ (tested with Node 24).
```sh
npm ci
npm run dev
```
Production: `npm run build && npm start`. Type check: `npm run typecheck`.

## Content and maintenance
Edit business details, review excerpts, links and service copy in components/Salon.tsx.
Global styling is in app/globals.css; SEO metadata is in app/layout.tsx.
WhatsApp and phone links use the supplied +92 324 8650251. WhatsApp account availability must be confirmed by the owner. Booking is an enquiry, not an automated confirmed reservation.
Services are drawn from the supplied reviews and review topics. Bridal availability is explicitly unconfirmed. No prices or full opening schedule were supplied.
Review counts reflect supplied information, not a live feed.
Images are remote Unsplash editorial illustrations, explicitly labeled, not salon/client photos. Replace these with licensed owner-approved assets before launch. Images require images.unsplash.com access. No reference attachments were accessible.
No backend, tracking, or form data storage is required. Contact goes directly to WhatsApp or telephone.
Before deployment, confirm all business details and replace editorial imagery as desired. Add your final domain to metadata when known.
